⚡ ASAP Powertools — Page Inspector

One-click screen mapper. Run it on any ASAP Connected page to extract its structure — no PII, just labels and element IDs — then paste the output into the chat to plan automation.

Step 1 — Add to your bookmarks bar

1

Make sure your browser's bookmarks bar is visible.
Chrome / Edge: Ctrl+Shift+B  |  Firefox: Ctrl+Shift+B

2

Drag the button below up to your bookmarks bar and drop it there.

🔍 Inspect Page

Can't drag? Right-click the button → Bookmark this link.

Step 2 — Use it on any ASAP screen

1

Navigate to any ASAP Connected screen.

2

Click 🔍 Inspect Page in your bookmarks bar.
A popup appears with the page's structure already inside it.

3

Click the Copy button inside the popup.

4

Paste into the chat. Done — no DevTools needed.

🔒 Privacy guarantee: Field values are always replaced with [REDACTED]. Only labels, element IDs, and page structure are captured — no student names, dates, IDs, or any other data.
